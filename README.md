 # Personal Profile Website

A lightweight, clean, and fully responsive personal portfolio website built **exclusively using pure HTML**. This project focuses on semantic markup, fast loading times, and standard web accessibility without relying on external CSS frameworks or JavaScript libraries.

## 🚀 Features
* **100% Pure HTML:** Built entirely with semantic tags (`<header>`, `<section>`, `<article>`, `<footer5>`) for structural clarity.
* **Fast & Lightweight:** Zero dependencies mean near-instant loading speeds.
* **SEO & Accessibility Friendly:** Clean element nesting for better screen-reader compatibility and search indexing.
* **Organized Layout:** Includes dedicated sections for a Bio, Skills, Projects, and Contact Information.

## 🛠️ Tech Stack
* HTML5 only
